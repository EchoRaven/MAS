# Game of 24

`game24-50.jsonl`: fifty games of 24, generated by `build.py`. Every multiset of four numbers from 1 to 13 is
solved exhaustively; the 50 with the fewest distinct solutions are kept (ties broken with seed 0), as a stand-in
for the hardest games (Meta-Prompting and Tree of Thoughts use 4nums.com's games ranked 901–1,000 by human solving
time). The question is Meta-Prompting's task description; `expected` holds the four numbers, and each record keeps
one solution (`example`) and the solution count.

Grade with `check` and `check.js`: the final answer must be an expression using exactly those four numbers once
each and equal 24. Every stored example passes it.
