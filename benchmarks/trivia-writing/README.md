# Trivia Creative Writing

`trivia-writing-20.jsonl`: twenty tasks in the form of Solo Performance Prompting's Trivia Creative Writing (Wang et
al. 2024): "Write a short and coherent story about {topic} that incorporates the answers to the following 5
questions: …". The questions were written for this project from well-known facts, generated by `build.py` (seed 0).
Every answer is a name or a specific term (Jupiter, Canberra, Beethoven), never a number or a common word a story
would use anyway, so an answer found in a story was put there. `expected` is a JSON list of each question's aliases.

Grade with `check` and `check.js`: a story passes when it contains every answer (any alias, whole words, case
ignored); the reason says how many of the five it found, the paper's metric. The paper's GPT-4, N = 5: standard
prompting 74.6%, SPP 79.9%.
